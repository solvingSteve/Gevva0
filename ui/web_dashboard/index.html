Gevva0 Architecture & Guide
v0.1.0

Multi-Tier Decision Gateway

Gevva0 routes decisions through specialized tiers to deliver sub-50ms logit-scored classifications without wasting compute on unnecessary autoregressive token generation:

  • Tier -1: Heuristic Rules (<0.05ms): Deterministic regex and keyword matching without model invocation.
  • Tier 0: Embedding Early Exit (<3ms): Gemma-2 768D absorbing Markov chain for high-margin prototype classification. We plot the meaning of your words onto a high-dimensional concept map and let probability naturally flow across nearby examples into final decision buckets using a network random walk. If the flow drains decisively into a single choice with near-zero uncertainty, the system locks the answer in under 3 milliseconds without ever waking up an LLM.
  • Tier 1: Direct Logit Fast-Path (<50ms): Single forward pass evaluating candidate option tokens directly from output logits. Evaluates candidate token log-probabilities directly from `llm.scores[llm.n_tokens - 1]`. Marginalizes over bare and space-prefixed tokens (`logsumexp(logit(" A"), logit("A"))`) to capture true prior distributions without running an autoregressive decoding loop.
  • Tier 2: CoT Verification: Autoregressive verification scratchpad invoked only when calibrated confidence is low.
