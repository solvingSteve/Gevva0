Tier 0 · Absorbing Markov Chains

Geometry instead of generation.

The query is embedded with EmbeddingGemma 2 (740M params, 768D). It then takes a random walk across domain landmarks until it lands in one of the candidate answers, and the landing probabilities are computed in closed form.

B = (I − Q)−1 R
Q: landmark→landmark transitions · R: landmark→answer absorption · final = 0.65·cosine + 0.35·Markov

Tier 1 · Fast-Path

One forward pass. Zero tokens generated.

Gemma 4 26B-A4B (MoE, 4B active) reads the answer-letter logits directly from a single forward pass. The scores are auto-calibrated with Platt temperature scaling, so the confidence values can be trusted.

Only 52 tokens matter: ' A'…' Z' and 'A'…'Z'. So we patched the output head to project onto a 64-row slice instead of the full 262,144-token vocabulary.

Tier 2 · Bounded Chain-of-Thought

Reason only when it pays off.

When Tier 1 confidence is low, or a rule says FORCE_COT, the full LLM continues from the KV cache Tier 1 already filled. The prompt is never processed twice. It writes up to 256 tokens of reasoning (max_cot_tokens=256), then reads a calibrated answer.

The full vocabulary is restored only for the reasoning step (full_vocab_scope())
